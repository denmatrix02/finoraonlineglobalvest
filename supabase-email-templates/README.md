# Finora — Styled Supabase Email Templates

This folder contains pre-styled HTML email templates for your FINORA Digital Banking application.

## Files Included
1. **`otp-email.html`** — Styled 6-digit OTP security authorization code email template.
2. **`welcome-email.html`** — Styled welcome & onboarding email template for new users.

---

## How to Apply to Supabase Dashboard

1. Open your [Supabase Dashboard](https://supabase.com/dashboard).
2. Go to **Authentication** ➔ **Email Templates**.
3. Select **Magic Link / OTP** or **Confirm signup**:
   - Copy the code from [`otp-email.html`](./otp-email.html).
   - Paste it into the HTML message body box.
   - Click **Save**.
4. Test sending an OTP during a transfer or signup to see your high-end dark theme email in action!
